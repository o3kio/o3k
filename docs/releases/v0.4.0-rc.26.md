# O3K v0.4.0-rc.26

PP.6 Stage 2 installed-release qualification candidate. PP.6 remains BLOCKED.
This prerelease is not production-ready and is not PP.6-certified. No PP.7 or
Araf certification is claimed.

The candidate carries the PP.6 recovery-source milestones merged since rc.24
(#1198-#1207), including the signed release-provenance compatibility fixes
required by the installed qualification harness.

Explicit limits:

- the production bundle intentionally excludes `o3k recovery-migrate-v2`;
  publisher process evidence is qualification-only and is not an installed
  production migration capability;
- signed journal-v2 Phase B is an authenticated consumer, not an operational
  restore capability;
- PostgreSQL restore-target mutation and controller activation are not
  authorized;
- clean Debian 12 and Ubuntu 24.04 installation, operational recovery,
  independent security acceptance, and final owner GO remain outstanding.

This candidate does not claim full OpenStack or Horizon parity. The published
`alpha` channel remains unchanged, and the minimum supported upgrade source
remains `v0.4.0-rc.5`.

Authenticity requires the protected O3K GitHub Actions release workflow, its
`release` environment approval, GitHub OIDC, and a Sigstore keyless bundle.
The prerelease is immutable by policy; defects require a successor candidate.
Preparing these notes does not create or authorize the tag or release.
