# O3K v0.4.0-rc.6 — PP.4 release candidate (prerelease)

Successor candidate to `v0.4.0-rc.5` (immutable; never retagged), produced
by PP.4 (issue #973). It is a **prerelease**: it is not release-gate approved
and it makes no production, scale, or support claims beyond the evidence
attached to the PR closing #973.

## What changes in RC.6 (PP.4, issue #973)

- **One-line installer Araf demo integration.** The public one-line installer
  (`packaging/get-o3k.sh`, published byte-identically as the `install.sh`
  release asset) now deploys the pinned Araf demo tuple as its final stage,
  after the canonical P15.6 bootstrap and the bounded TestLab workload:
  O3K `v0.4.0-rc.6` + Araf `v1.0.0-rc.12` (Araf source
  `de64cc9193085116fa30ad51c04ccab24a013dd0`; the Araf image digests stay
  exactly as pinned in `contracts/araf-compatibility-v1.yaml`). The demo
  deployment material is copied from the verified release bundle into
  `/usr/local/share/o3k/araf-demo/` so post-reboot and convergent reruns do
  not need the bundle. A demo-stage failure aborts the installer with a
  retry hint; O3K itself stays healthy and the stage can be re-run from the
  installed copy.
- **Debian 12 demo support.** The Araf demo deployment now accepts both
  frozen targets, Ubuntu 24.04 and Debian 12 (x86_64). Debian 12 installs the
  pinned upstream Docker static binaries (`28.5.2`, sha256-pinned) plus the
  pinned Docker Compose v2 plugin (`v2.39.4`, sha256-pinned) because
  bookworm's `docker.io` (20.10) is below the Docker >= 24.0 contract
  minimum; Ubuntu 24.04 keeps the proven apt (`docker.io` +
  `docker-compose-v2`) path.
- **Operator output.** The installer ends with a browser-ready summary
  (tenant/operator console URLs, O3K API, CLI config paths, the demo login
  pointer, uninstall instructions) and records stage timing stamps (T0–T5)
  in `/var/lib/o3k/install-timestamps.env`. The demo orchestrator exposes a
  `tuple` subcommand that prints the pinned tuple read fail-closed from the
  installed release manifest, and writes a root-only (0600) operator
  credentials file whose contents are never printed.

## What does NOT change

- The published `v0.4.0-rc.5` artifact is untouched (immutable; never
  retagged).
- The pinned Araf tuple is unchanged: Araf stays at `v1.0.0-rc.12` with the
  same digest pins; no Araf version or digest constant was modified.
- The PP.2 canonical bootstrap contract, the upgrade fence, and the O3K
  readiness independence boundary are unchanged.

Final PP.4 fresh-host campaign evidence is recorded separately; this note
makes no claim beyond the code and contract changes above.
